# تیمو ریموت

تیمو ریموت سامانهٔ کنترل از راه دور ربات تعاملی تیمو است. کاربر می‌تواند از برنامهٔ ویندوز یا مرورگر به ربات متصل شود، حرکت پایه را کنترل کند، تصویر دوربین را ببیند و دوطرفه صدا بفرستد. اپ همراه اندروید فرمان‌ها و وضعیت را از طریق Binder با SDK نصب‌شدهٔ سازنده ردوبدل می‌کند.

[English README](README.md) · [راهنمای ساخت اپ اندروید](README.md#build-the-android-apps)

## دمو روی کامپیوتر

با Python 3.11 یا جدیدتر از پوشهٔ اصلی پروژه اجرا کن:

```cmd
python -m pip install "Pillow>=10.4,<13"
python tests/demo_agent.py
```

نشانی [http://127.0.0.1:18765](http://127.0.0.1:18765) را باز کن و با رمز دمو `local-test-password` وارد شو. روی «فعال‌کردن کنترل» و «روشن‌کردن دوربین» بزن. با نگه‌داشتن یکی از فلش‌ها، درخواست حرکت و نتیجهٔ شبیه‌سازی‌شده را در پنل می‌بینی. تصویر و صدا در دمو مصنوعی‌اند و سرور دمو فقط روی همین کامپیوتر در دسترس است.

## مسیر یک فرمان حرکت

1. اپراتور کنترل را می‌گیرد. درگاه فقط یک کنترل‌کننده را هم‌زمان می‌پذیرد و مهلت کنترل را با درخواست‌های دوره‌ای تمدید می‌کند.
2. پنل هنگام نگه‌داشتن فلش، درخواست جهت را می‌فرستد. درگاه فرمان‌های قدیمیِ ارسال‌نشده را حذف می‌کند و به هر فرمان تازه شمارهٔ ترتیب و مهلت کوتاه می‌دهد.
3. اپ ربات فرمان را دریافت می‌کند و پس از بررسی مهلت، ترتیب و وضعیت ناوبری، آن را به SDK می‌دهد. با رهاکردن فلش یا منقضی‌شدن مهلت، اپ درخواست توقف می‌فرستد.
4. پنل نتیجهٔ ارسال و گزارش‌های SDK را نمایش می‌دهد. برای تأیید حرکت یا توقف فیزیکی، رفتار خود دستگاه در آزمون سخت‌افزاری بررسی می‌شود.

## بخش‌های اصلی کد

| بخش | فایل | جزئیات |
| --- | --- | --- |
| درگاه کنترل | [server.py](server.py) | نشست، صف فرمان، مهلت کنترل و نگهداری کوتاه تصویر و صدا |
| برنامهٔ ویندوز | [desktop.py](desktop.py) | پنل Tkinter و به‌روزرسانی رابط پس از دریافت پاسخ شبکه |
| نصب و اتصال اندروید | [quick_connect.py](quick_connect.py) | شناسایی دستگاه مجاز، نصب APK و تنظیم ارتباط با ADB |
| اپ روی ربات | [RobotAgent.java](android/robot/src/main/java/com/htnhome/timoremote/robot/RobotAgent.java) | ارتباط با درگاه و مسیردهی فرمان‌ها به SDK |
| ناوبری | [NavigationControl.java](android/robot/src/main/java/com/htnhome/timoremote/robot/NavigationControl.java) | ماشین حالت مسیر و بررسی پایان ناوبری پیش از آزادشدن حرکت دستی |
| اتصال دستیار تیمو | [project_link.py](project_link.py) و [project_control.py](project_control.py) | خواندن نقشه و اتاق‌ها، بررسی مجدد مقصد، چت و ارسال صوت پاسخ |

مقصد از فهرست اتاق‌های ثبت‌شده در بک‌اند FastAPI خوانده می‌شود. تغییر نسخهٔ نقشه یا مختصات میان ثبت و تحویل فرمان باعث رد درخواست می‌شود. اتصال دستیار اختیاری است و برای کنترل دستی، دوربین و دموی محلی لازم نیست.

## اجرا روی ویندوز و ربات

1. از ریشهٔ پروژه `Start_Windows.bat` را اجرا کن. در اجرای اول، برنامه فایل محلی `config.json` را می‌سازد.
2. [اپ اندروید ربات را بساز](README.md#build-the-android-apps) و فایل `robot-debug.apk` را با نام `TimoRemote-Robot.apk` داخل پوشهٔ `apks` بگذار.
3. اتصال مجاز دستگاه را با `adb devices` بررسی کن و در برنامهٔ ویندوز «اتصال ربات» را بزن. اپ همراه روی خود ربات باید در پیش‌زمینه باشد.

نسخهٔ APK ساخته‌شده با کلید Debug محلی، برای نصب آزمایشی است. برای ارتقای نصب فعلی ربات، بسته باید با همان کلید نصب قبلی امضا شود. درگاه برای شبکهٔ خصوصی طراحی شده و امکانات حرکتی به SDK و پروفایل دستگاه وابسته‌اند.

## بررسی نرم‌افزاری

- آزمون‌های Python رفتار نشست، انقضای فرمان، صف، مقصد و رسانه را بررسی می‌کنند.
- آزمون‌های Java منطق حرکت پایه، تأیید پایان ناوبری و کنترل مرحله‌ای بازو را با ساعت و مسیر ارسال شبیه‌سازی‌شده بررسی می‌کنند.
- آزمون‌های Node رفتار پنل، چهره‌ها و مسیر صدای مرورگر را بررسی می‌کنند.

پیش‌نمایش پنج حالت نمایشگر در [face-preview/index.html](face-preview/index.html) است. کد نمایشگر برای استفادهٔ آفلاین در [face.html](android/robot/src/main/assets/face.html) قرار دارد.
